Where mide sits.

Sublime is fast but leaves git and the terminal to other apps. VS Code has everything, and a lot you did not ask for. mide keeps the part you use every day.

Sublime Text

Minimal, but incomplete.

Fast and calm, with no built-in git and no real terminal. You switch apps to commit, review history or run an agent.

VS Code

Complete, but overwhelming.

Extensions, panels, settings and a web runtime underneath. Powerful, though it takes setup and attention to keep it out of your way.

One window for the whole job.

An editor with Sublime's reflexes

Multi-cursor, regex find and replace, line commands and the shortcuts you already know. Colors come from Sublime syntax definitions.

Git history you can act on

A commit graph, side-by-side diffs, staging, commit, push, pull, branches and stash, without leaving the editor.

Terminals that dock anywhere

Real sessions for your shell, Claude Code, GitHub Copilot or vim. Drag the panel to the bottom, left or right.

A closer look.

Screenshots of mide working on its own source code.

Rust, drawn on the GPU.

No web view and no Electron. Text lives in a rope, highlighting is incremental, the terminal sleeps until output arrives, and git work stays off the interface thread.

How it is built

The installer is about 6 MB. Dark and light themes follow your Mac, and the terminal changes with them.

Configure it in TOML

Install in a minute.

One command installs it on Apple Silicon or Intel, then start from any terminal.

curl -fsSL -o /tmp/mide.pkg https://github.com/kmr-rohit/mide/releases/latest/download/mide-0.3.0-universal.pkg && sudo installer -pkg /tmp/mide.pkg -target /
mide ~/code/my-project
