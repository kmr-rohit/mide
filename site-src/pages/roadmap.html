Status and roadmap

mide is young. Here is what is solid, and what is missing.

Solid today

  • Opening, editing and saving files of any practical size, with multi-cursor, find and replace, and the common line commands.
  • Syntax highlighting for the languages in the Sublime and bat grammar sets.
  • A git window with history, diffs, staging, commit, push, pull, branches and stash.
  • Terminal sessions with profiles, docking, mouse support, Claude Code and GitHub Copilot.
  • Light and dark themes, a command palette, go-to-file and a saved layout.

Next up

Things that can cost you work are first.

  1. Notice files that change on disk. Today an open file is not refreshed when a formatter or git checkout changes it, and saving would overwrite that change. Clean buffers should reload, and edited ones should ask.
  2. Restore your session. Reopen tabs, positions and layout after a quit or crash, and back up unsaved edits.
  3. New file, Save As, and file operations in the sidebar: create, rename, delete, reveal in Finder.
  4. Find in files.

Soon after

  • Detect indentation (2 or 4 spaces, or tabs) per file, and auto-indent.
  • Scrollbars and a minimap, soft wrap, split panes, code folding.
  • A virtualized sidebar for very large folders.
  • Tab bar overflow and reordering; right-click menus.
  • Language server support: completion, go to definition, diagnostics.
  • A faster path for extremely long lines, and a background search for huge files.

Git and terminal depth

  • Stage by hunk and by line, resolve conflicts, show blame and change markers in the gutter, rebase, delete and rename branches, search history.
  • Search in the terminal, clickable links and paths, split sessions.
  • Send the current file or selection to a Claude or Copilot session, and open the files an agent just changed.

Distribution

  • Developer ID signing and Apple notarization, so the installer opens without a warning.
  • A universal package for Intel Macs published with every release, and Homebrew.
  • Automatic updates and a diagnostics file for bug reports.

Help shape it

Found a bug or want something moved up? Open an issue. The most useful reports say what you did, what you expected, and what happened.
