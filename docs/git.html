Git

History, diffs and the everyday git actions in one window.

Open it

Press ⌃⇧G, or click the git text at the bottom left. Esc brings your editor back. When you open a folder that is a repository, its history loads in the background, so the window is ready when you ask for it.

Layout

AreaWhat is in it
Locations (left)Branches, remotes, tags, stashes, submodules and worktrees with counts. Click a branch or tag to find its commit; double-click a branch to switch to it.
Commits (middle)A colored graph rail showing merges and forks, the subject, author, date and branch or tag badges. Use ↑ ↓ PgUp PgDn Home End to move.
Details (right)Hash, author, date, parents, the full message, and every changed file as a side-by-side diff with the changed characters highlighted. Click a file name to open it in the editor.

Drag the dividers between the columns to resize them.

Toolbar

Commit, Pull, Push, Fetch, Branch, Stash and Pop Stash sit across the top, with the current branch and how far ahead or behind it is. Operations run the real git program in the background, so your credential helper, SSH agent and hooks work exactly as they do in a terminal. The result, or git's error message, appears in a banner. Only one operation runs at a time.

Committing

When the working tree has changes, the first row in the list reads "N uncommitted changes". Select it to see the working copy:

  • Stage, Unstage and Discard per file, and Stage all or Unstage all. Discarding asks you to confirm.
  • A commit message box. Press ⌘↩ to commit.
  • Amend last commit, which fills the box with the previous message.
  • If nothing is staged but there are changes, mide offers to stage everything and commit.

Working with a commit

Select any commit for these actions: Checkout (detached), New Branch from that commit, Cherry-pick, Revert and Copy Hash. Cherry-pick and revert are not offered for merge commits.

What it does not do yet

  • Staging is per file; there is no hunk or line staging.
  • No merge-conflict resolution screen, rebase, tag creation or branch deletion.
  • History shows the newest 2,000 commits, with no search or filter.
  • No change markers in the editor gutter and no blame.
  • An SSH key with a passphrase and no agent cannot prompt for the passphrase; use an agent or a credential helper.

See the roadmap for what is planned.
