Guide

Everything you need to work in mide, and every shortcut.

Open a project

Press ⌘O and choose a folder. The sidebar shows its files, with ignored files dimmed. Click a file to open it, or press ⌘P and type part of its path.

Opening a different folder replaces the whole workspace: its files and terminal sessions close, and if a file has unsaved changes you are asked first. To keep your files and terminals instead, set keep_open_on_switch = true in the configuration.

Go to anything

ShortcutWhat it does
⌘PGo to file. Fuzzy matching over every file that git does not ignore.
⇧⌘FFind in files. Results stream in as you type; ⌥⌘C / W / R toggle case, whole word and regex. ↵ opens the match.
⇧⌘PCommand palette: every command, with its shortcut.
⌃GGo to line. Type 120 or 120:8.
⌘OOpen a folder.
⌘BShow or hide the sidebar.

Windows, menus and git in the editor

⇧⌘N opens another window and ⌥⌘O opens a folder in a new one. Right-click the editor for the actions that apply to your selection, a tab for close and path actions, and a sidebar row for file operations.

Lines that differ from the staged file get a marker on the left edge of the gutter: green for added, blue for modified, red for deleted. Right-click a changed line for Stage Hunk (stages only that hunk) or Revert Hunk, and jump between changes with ⌥⌘↓ and ↑. The status bar shows who last changed the line you are on.

Send Selection to Terminal pastes the selected text, with its file and line numbers, into the active terminal session; Send File Path pastes @path into a Claude or Copilot session. Nothing runs until you press Enter.

Files and tabs

New files (⌘N), Save As (⇧⌘S) and a right-click menu in the sidebar (new file or folder, rename, reveal in Finder, copy path, move to Trash) are built in. If a file changes on disk while it is open, a clean tab reloads by itself; a tab with unsaved edits shows a bar asking you to reload or keep yours. mide also reopens your tabs and caret positions next time, and recovers unsaved text after a crash.

ShortcutWhat it does
⌘SSave. Saving is atomic, and Windows line endings are kept.
⌘WClose the tab (or the terminal session, when a terminal has focus). A tab with unsaved changes asks for a second press.
⌃Tab / ⌃⇧TabNext and previous tab. ⇧⌘] and ⇧⌘[ also work.
⌘QQuit. With unsaved files it asks you to press again.

Editing

ShortcutWhat it does
⌘Z / ⇧⌘ZUndo and redo. A run of typing, or of backspaces, is one step; a pause or Enter starts a new one.
⌘X ⌘C ⌘VCut, copy, paste. With nothing selected, cut and copy take the whole line.
⌥← ⌥→Move by word. Add ⇧ to select.
⌘← ⌘→Line start and end. The first press goes to the first non-blank character.
⌘↑ ⌘↓Start and end of the file.
⌥⌫Delete the previous word.
⇧⌘DDuplicate the line or selected lines.
⌃⇧KDelete the line.
⌃⌘↑ ⌃⌘↓Move the line up or down.
⌘JJoin lines.
⌘] ⌘[Indent and outdent. Tab and ⇧Tab do the same when several lines are selected.
⌘/Toggle a comment. The marker (//, #, --) follows the language.
⌘↩ ⇧⌘↩Open a new line below or above, keeping the indentation.

⌘LSelect the line; press again to take the next line too.
⌘DSelect the word under the cursor; press again to add the next match as another cursor.
⌃⌘GSelect every occurrence.

Find and replace

Press ⌘F for the find bar, or ⌥⌘F to add the replace row. Matches are highlighted as you type and the bar shows your position, such as "3 of 12". A search never spans a line break, so ^ and $ match at each line's ends.

ShortcutWhat it does
↩ / ⇧↩Next and previous match. In the replace field, ↩ replaces the current match.
⌘G / ⇧⌘GNext and previous match, even with the bar closed.
⌘EUse the selection as the search text.
⌥⌘C ⌥⌘W ⌥⌘RToggle case sensitive, whole word, regular expression.
⌥⌘↩Replace all, as one undo step.
EscClose the bar.

In regular expression mode the replacement can use $1 and ${name}.

Panels and views

ShortcutWhat it does
⌃⇧GShow or hide git history. Esc closes it.
⌃`Show or hide the terminal.
⌘⇧TNew terminal session; pick a profile.
⌥⌘TSwitch between the light and dark theme.

Drag the edges between panels to resize them. Drag the terminal's header toward the left, right or bottom edge of the window to dock it there. Sizes and the dock position are remembered.

Themes

The light and dark themes cover the sidebar, tabs, status bar, git window, command palette and the terminal, so they always match. The text editor keeps its own dark theme in both, by design. The choice is saved.
