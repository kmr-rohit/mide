Architecture

Small Rust crates for the engine, and one GPU-drawn interface on top.

Why it is fast

  • Native, no web view. The interface is drawn directly on the GPU with GPUI, the UI framework from Zed. There is no browser engine and no JavaScript runtime.
  • A rope for text. The document is a balanced tree of chunks, so inserting in the middle of a 35 MB file costs microseconds and a copy of the whole file is never made.
  • Only what you see. Each frame lays out the visible 50 or 60 lines. Everything else is untouched.
  • Incremental highlighting. The syntax parser saves its state every 64 lines, so an edit re-parses only what changed, and a far jump starts from a short warm-up.
  • Nothing slow on the interface thread. Git status and history load in the background. The terminal wakes the interface only when output arrives, so an idle terminal costs nothing.

The engine crates have no interface code in them, so they are tested on their own: unit tests, plus integration tests against real git repositories (including push and pull against a real remote) and real terminal sessions. There are about 150 automated tests.

How a keystroke travels

  1. macOS delivers the key to the editor view, which turns it into an action such as "insert a character".
  2. The buffer applies the edit to the rope and merges it into the current undo step.
  3. The highlighter forgets cached colors from the edited line down.
  4. On the next frame, the editor view re-lays-out the visible lines (most are cached), paints selections, matches, text and carets, and asks the GPU to draw them.

That is 4 to 5 ms of work in total, against a 16 ms budget.

Safety

  • Saves write a temporary file and rename it over the original, so a crash cannot leave half a file.
  • A file that is not valid UTF-8 still opens, but mide refuses to save over it rather than corrupt it. Windows line endings and a byte-order mark are preserved.
  • Unsaved changes are confirmed before closing a tab, quitting, or switching folders.
  • Workspace trust stops a downloaded project from running commands when you open it.
  • Git operations use your own git, credentials and hooks; mide stores no secrets.

Dependencies and licenses

mide itself is MIT licensed. It is built from 525 open-source Rust crates, and an automated check confirms none of them is under a copyleft license such as GPL or AGPL. The full list is in THIRD_PARTY_LICENSES.md. No fonts are bundled; mide uses fonts already on your Mac.
