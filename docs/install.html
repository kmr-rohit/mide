Install mide

A macOS installer, or build it yourself in a few commands.

Requirements

  • macOS 12 (Monterey) or later.
  • Apple Silicon for the arm64 package. For an Intel Mac, use the universal package if the release lists one, or build from source.
  • git on your PATH for the git window (it comes with the Xcode command line tools).

Install from the terminal

The quickest way, on Apple Silicon or Intel. One command downloads the latest release, checks its checksum, installs mide.app and adds the mide command. macOS does not show the unverified-developer warning for files fetched this way.

curl -fsSL https://raw.githubusercontent.com/kmr-rohit/mide/main/scripts/install.sh | sh

Then run mide . in a project folder. Releases that include a disk image install without a password, into /Applications (or ~/Applications if that is not writable). Older releases use the installer package and ask for your password once.

You can read the script first: it is scripts/install.sh, about a hundred lines.

Install with a disk image

  1. Download mide-0.2.0-universal.dmg from the latest release, if it lists one.
  2. Open it and drag mide onto Applications.

The same Gatekeeper note as below applies until the app is notarized.

Install with the package

  1. Download mide-0.2.0-arm64.pkg (or the universal one) from the latest release.
  2. Open it and follow the installer. It puts mide.app in /Applications and adds a mide command to /usr/local/bin.
  3. Open mide from Applications, or run mide . in a project folder.

To check the download, compare its checksum with the .sha256 file on the release page:

shasum -a 256 -c mide-0.2.0-arm64.pkg.sha256

Prefer the command line? This installs without the window:

sudo installer -pkg mide-0.2.0-arm64.pkg -target /

If macOS says it cannot be opened

mide is not yet notarized by Apple, so Gatekeeper shows an "unidentified developer" warning the first time. This is expected for an independent open-source app, and it is safe to continue if you downloaded the installer from this project's release page.

If you see "mide-0.2.0-arm64.pkg" Not Opened with only Move to Trash and Done, choose Done, then either:

  • open System Settings, Privacy & Security, scroll down to the message about the package and choose Open Anyway, then confirm; or
  • remove the download flag from the terminal and open it again: xattr -d com.apple.quarantine ~/Downloads/mide-0.2.0-arm64.pkg

On macOS 15 (Sequoia) and later, Control-click and Open no longer skips this check; use one of the steps above, or the terminal install.

First launch

You get a welcome screen with Open Folder and your recent folders. Press ⌘O to pick a project. If it is a git repository, its history is ready in the background and ⌃⇧G shows it. Press ⌃` for a terminal. The guide covers the rest.

The mide command

mide                  # open the app
mide ~/code/project   # open a folder
mide notes.md         # open a file (and its folder)

It is a small script inside the app, linked into /usr/local/bin by the installer.

Build from source

You need the Rust toolchain and the full Xcode app (not just the command line tools), because the GPU interface compiles Metal shaders.

xcodebuild -downloadComponent MetalToolchain   # once, after installing Xcode
git clone https://github.com/kmr-rohit/mide.git
cd mide
cargo run --release -p mide -- .

Build the app bundle or the installer yourself:

scripts/bundle.sh --install    # build mide.app and copy it to /Applications
scripts/pkg.sh                 # build dist/mide-0.2.0-arm64.pkg
scripts/pkg.sh --universal     # Apple Silicon and Intel in one package

Update

Run the install command again, or open a newer installer; it replaces the app in place. Your settings in ~/.config/mide are kept.

Uninstall

If you installed with the script, download it and run it with --uninstall; it removes only the app and the mide link it knows about:

curl -fsSL -o /tmp/mide-install.sh https://raw.githubusercontent.com/kmr-rohit/mide/main/scripts/install.sh && sh /tmp/mide-install.sh --uninstall

Or by hand (packages put the app in /Applications as root, hence sudo):

sudo rm -rf /Applications/mide.app /usr/local/bin/mide
rm -rf ~/.config/mide      # optional: settings, recent folders, trusted folders
