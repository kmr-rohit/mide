Status and roadmap

mide is young. Here is what is solid, and what is missing.

Solid today

  • Opening, editing and saving files of any practical size, with multi-cursor, find and replace, find in files, and the common line commands. Find on a million-line file takes about a millisecond.
  • Safety nets: files changed on disk are noticed, tabs and unsaved edits come back after a quit or crash, and binary files are refused before they are read.
  • Syntax highlighting for the languages in the Sublime and bat grammar sets, indentation detection, auto-indent and auto-closing brackets.
  • A git window with history, side-by-side diffs, staging, commit, push, pull, branches and stash, plus gutter markers, hunk staging and blame in the editor.
  • Terminal sessions with profiles, docking, mouse support, Claude Code and GitHub Copilot, and sending a selection or file path to a session.
  • Right-click menus, draggable tabs, multiple windows, a keymap file, light and dark themes, a command palette and go-to-file.

Next up

  1. More language server features: code completion, hover documentation, go to symbol, rename and find references. Errors, warnings and Go to Definition already work.
  2. Signed and notarized installer, so it opens without a warning, plus a disk image and Homebrew.
  3. Editor layout: split panes, soft wrap, code folding and a minimap.
  4. Linux support. The GPU toolkit runs there; the terminal, file watching and packaging need work.

Git and terminal depth

  • Stage by line, resolve conflicts, rebase, delete and rename branches, search history.
  • Search in the terminal, clickable links and paths, split sessions.
  • Send the current diff to an agent session, and open the files an agent just changed.

Later

  • Automatic updates and a diagnostics file for bug reports.
  • A faster path for extremely long lines (a 3 MB minified line costs about 47 ms per keystroke today).
  • A settings screen, so the TOML file is optional.

Help shape it

Found a bug or want something moved up? Open an issue. The most useful reports say what you did, what you expected, and what happened.
